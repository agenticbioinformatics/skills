# skills

- **hackathon-brainstorm** — Turns a rough hackathon problem statement into a scoped, peer-reviewed pipeline plan (README.md + PROMPTS.md) before any code is written.
- **hackathon-firstprot** — Builds the first minimal, working end-to-end prototype for a scoped hackathon idea, complete with a small synthetic example dataset and run/test instructions.
- **hackathon-cleanup** — Turns a messy hackathon repo into an organized, documented, minimally-tested pipeline, logging every change to a prompt_history file.
